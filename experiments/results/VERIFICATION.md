# 검증 결과

이 문서는 이전 독립 실험의 결과다. 현재 `final.xpr` 보드 통합 검증과 다운로드 안내는
작업 폴더의 `README.md` 및 `board/VERIFICATION.md`를 따른다.

실행일: 2026-11-18 (한국 시간). 도구: Vivado/XSim 2024.2.
대상: `xc7s75fgga484-1`. 실물 보드는 사용하지 않았다.

우사기 스프라이트 개선 후 색 카드·LCD 시뮬레이션과 해당 경로의 합성을 재실행했다.
현재 화면은 128x128, 4비트, 두 표정이며 스프라이트 ROM은 합계 16KiB다.
긴 귀, 넓은 얼굴, 아치 눈썹, 반짝이는 눈, 볼 빗금과 W자 입을 제공된 참고에 맞췄다.
스프라이트 원화와 RTL 출력 화면의 캐릭터 영역은 픽셀 단위로 일치했다.
뉴런 회로는 이번 변경에 포함되지 않았으며 아래 학습 검증은 앞선 실행 결과다.

## 시뮬레이션

| 항목 | 결과 | 근거 |
|---|---|---|
| RGB565 수신·중앙 ROI 검출 | 통과 | 노란색/파란색 대조, 연속 3프레임 판정 |
| 불완전 영상 거부 | 통과 | 홀수 바이트 줄, ROI 일부만 수신한 프레임 |
| 카메라/LCD 도메인 전달 | 통과 | 서로 다른 주기의 클록, 16회 payload 무결성 비교 |
| 가상 센서부터 통합 코어까지 | 통과 | 표정 상태 진입, 카메라 클록 정지 시 해제, 재개 시 복구 |
| LCD 래스터·렌더러 | 통과 | 800x480 두 표정 출력, active 픽셀 수·HS/VS 폭 |
| 학습 RTL/정수 기준 모델 | 통과 | 39,600단계, 15개 상태값 전부 정수 단위 일치 |
| step_en 비활성 시 상태 유지 | 통과 | 모델 갱신 정지 시 v/u/가중치 유지 |

로그: `card_run.log`, `display_run.log`, `conditioning_run.log`.
프레임 이미지: `display_neutral.png`, `display_happy.png`.
이미지는 XSim이 출력한 프레임버퍼를 변환한 것이며 실제 LCD 촬영 사진이 아니다.

### 조건반사 수치

각 시험 구간은 모델 시간 200ms이다. 학습 구간에만 카드와 먹이를 8회 짝지었다.

| 조건 | 기대 반응 뉴런의 발화 수 |
|---|---:|
| 학습 전 카드 단독 | 0 |
| 학습 후 카드 단독 | 12 |
| 학습하지 않은 대조 색 | 0 |
| 휴식 후 카드 재시험 | 12 |

최종 학습 가중치 24, 대조 색 가중치 0. 시험 중 가중치 변경과 수치 클리핑은 없었다.
이는 고정한 이상적 자극·파라미터의 결과다. 카메라 입력이나 다양한 사용자 조작에서의
성공률을 측정한 결과는 아니다. 학습은 먹이로 게이트된 인과적 강화 규칙이다.

## 독립 합성

배치·배선 전 out-of-context 결과이며 I/O buffer, 보드 wrapper,
센서 초기화와 실제 클록 생성 회로는 포함하지 않는다.

| 회로 | LUT | FF | DSP | BRAM36 | 내부 클록 가정 | 합성 WNS |
|---|---:|---:|---:|---:|---|---:|
| 색 카드·LCD, 실제 입력 경로 | 437 | 362 | 1 | 4 | 카메라 24MHz / LCD 33.333MHz | +22.060ns |
| 뉴런 3개·학습 시냅스 | 3854 | 286 | 12 | 0 | 25MHz | +10.972ns |

참고: 대상 디바이스의 보고 자원은 LUT 48,000, FF 96,000, DSP 140, BRAM36 90이다.
현재 실험 두 개는 각각 합성한 것이므로 위 합계가 통합 설계의 실제 사용량은 아니다.
확대 배율을 3배에서 2배로 바꾸면서 상수 나눗셈 회로가 단순해져 LUT 사용량이 줄었다.
스프라이트 해상도를 늘리면서 BRAM36 사용량은 1개에서 4개로 증가했다.

뉴런 회로의 최초 50MHz 시도는 **WNS -9.028ns, 실패**였다.
기준 모델의 갱신률은 4kHz이므로 현재 실험 목표는 25MHz 코어로 조정했다.
연산 회로·숫자 형식을 바꾼 것은 아니며, 별도의 파이프라인은 추가하지 않았다.
50MHz 결과는 `conditioning_50mhz_synth_timing.rpt`에 보존했다.

합성 타이밍은 clock insertion/skew 및 물리적 배선이 확정되지 않은 추정이다.
Vivado도 OOC clock source 위치 미지정 경고를 보고한다.
실물 핀과 입력/출력 지연이 없는 상태이므로 "보드 타이밍 통과"를 뜻하지 않는다.

## 남아 있는 실물 검증

- 카메라 모델/레지스터 설정, RGB565 지원 여부, 핀·극성·클록.
- 패널 해상도 충돌(강의 p.71 800x600 / p.72 800x480)과 전체 타이밍.
- 모듈 리비전, I/O 전압, PDF에서 중복된 핀의 실제 연결.
- 조명·거리별 색 검출 성공률, 카드 제시부터 반응까지 지연.
- 실제 배치·배선 타이밍, 센서/LCD 클록 간 전달의 물리적 검증.

따라서 현재 결과는 **내부 회로의 시뮬레이션·합성 가능성 확인**이다.
하드웨어 완제품이나 다운로드 가능한 검증 완료 bitstream은 제공하지 않는다.
