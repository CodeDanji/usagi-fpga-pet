# 색·방향·가위바위보 인식 시험 화면

2026-11-20. 후속 진단 기능. 실물 클록 B6 / F=50MHz 유지.

## 목적과 판정 범위

기존의 노란색 ON/OFF와 영상 변화량만으로는 "어떻게 보고 있는가"를 확인하기 어렵다.
새 화면은 입력 영상, 색 이름, 방향 이름, 배경 분리 실루엣, 등록한 모양과의 차이를 보여 준다.
색·방향·모양의 결과는 진단용이다. 기존 뉴런의 조건반사 학습과 별개이며 자동 연결하지 않았다.

- 색: BLACK, WHITE, GRAY, RED, ORANGE, YELLOW, GREEN, CYAN, BLUE, MAGENTA.
  조건이 모호하면 UNKNOWN. 조명 불변 분류기가 아니라 RGB 규칙 기반이다.
- 방향: STILL, LEFT, RIGHT, UP, DOWN, DIAGONAL. 배경 등록 전 NEED BG,
  물체가 없거나 너무 크게 차지하면 NO TARGET. 카메라 영상의 좌표를 따른다.
- 모양: 사람이 ROCK / PAPER / SCISSORS라는 이름으로 각각 등록한 실루엣 템플릿을 비교한다.
  임의 물체의 의미를 알아내는 모델이나 뉴런 기반 손 인식은 아니다.
  컵을 ROCK으로 가르치면 그 컵 실루엣을 ROCK이라고 부를 수 있다는 한계가 있다.

## 다운로드 및 조작

새 파일: `C:/Users/sodas/.Xilinx/final/board/vision_lab/usagi_vision_lab.bit`.
Vivado Hardware Manager → Program Device로 선택한다. 자동 다운로드는 수행하지 않는다.
이전 `board/camera_diagnostics/usagi_camera_diagnostics.bit`에는 이 화면이 없다.

**DIP3·4 ON, DIP1·2·5 OFF → H 눌렀다 놓기.** 오른쪽 우사기 자리의 문자 패널이 시험 화면이다.

| 조작 | 시험 화면에서의 역할 |
|---|---|
| A | 등록할 모양 선택: ROCK → PAPER → SCISSORS → ROCK |
| B | 다음 전체 프레임을 선택한 모양의 템플릿으로 등록. 재등록하면 덮어씀 |
| C | 빈 배경 등록. 기존 세 템플릿을 모두 지움 |
| DIP2 ON | 청록색 사각형 내부를 흰 물체 / 검은 배경의 16×16 실루엣으로 표시 |
| DIP2 OFF | 원본 영상 표시 |
| H | 전체 초기화. 배경·세 템플릿·기존 뉴런 가중치도 지움 |

DIP1 ON에서는 원래 뉴런 모드이며 DIP2·3의 역할도 원래 학습 허용·자동 자극이다.
DIP3 OFF, DIP4 ON이면 기존 카메라/우사기 화면이다. 이때 DIP2는 기존 노란 픽셀 강조다.
버튼은 누른 뒤 놓고, 각 조작 후 약 0.5초 기다린다.

## 1. 색 시험

1. 초기 상태에서 각 색 종이로 중앙 노란 ROI를 충분히 채운다.
2. COLOR에 표시되는 이름과 점유율을 기록한다. 여러 색이 비슷하게 섞이면 UNKNOWN이 적절하다.
3. 작은 물체를 시험하려면 물체를 치우고 C로 빈 배경을 등록한다.
   이후 청록색 사각형에 물체 하나를 넣는다. 배경과 분리된 물체의 픽셀로 색을 판정한다.
4. DIP2 ON에서 물체 윤곽이 흰색으로 분리되는지 확인한다. 배경 전체가 하얗다면 배경부터 재등록한다.

표시 비율은 가장 많은 색의 점유율을 10% 단위로 내림한 값이다. 정답 확률이 아니다.
배경 등록 전에는 중앙 320×240 ROI의 4800개 표본, 등록 후에는 청록색 사각형의 전경 표본을 사용한다.
가장 많은 색이 40% 이상이며 둘째 색보다 10%p 이상 많을 때 이름을 출력한다.
배경 등록 후 전경 크기 조건을 벗어나면 UNKNOWN이다.
배경 등록 후 COLOR의 100%는 분리된 물체 안의 색 비율이다. 기존 우사기 반응은 여전히
노란 ROI 전체의 35% 조건을 사용하므로 작은 노란 물체가 YELLOW 100%로 표시돼도 표정이 바뀌지 않을 수 있다.

## 2. 방향 시험

1. 카메라·조명을 고정하고, 청록색 사각형을 비운 상태로 C를 누른다.
2. 배경과 색 또는 밝기 차이가 큰 물체 하나를 사각형 안에 넣는다.
3. 같은 모양을 유지하며 오른쪽 / 왼쪽 / 아래 / 위 / 대각선으로 움직이고 MOVE를 확인한다.
4. 멈추고 여러 프레임 기다리면 STILL로 돌아와야 한다. 영역을 비우면 NO TARGET이어야 한다.

전경의 경계 상자 중심을 추적한다. 누적 중심 이동이 약 32 카메라 픽셀 이상일 때 방향을 갱신한다.
한 축 이동이 다른 축의 2배 이상이면 그 축, 그렇지 않으면 DIAGONAL이다.
최근 방향은 가독성을 위해 8프레임 유지한다. 화면 좌표 기준이므로 거울 영상인지 실제 손 방향과 비교한다.
배경 분리는 RGB 중 한 채널 이상이 등록 배경과 32/255 이상 다를 때 전경으로 본다.
밝기는 같아도 색이 다른 물체가 사라지지 않도록 밝기 차이만으로 분리하지 않는다.
손 모양 변화, 여러 물체, 그림자, 조명 변화도 경계 상자를 바꿀 수 있다.
이는 광류나 손 정체성 추적이 아니다. 하단의 기존 영상 변화량 막대와 구분한다.

## 3. 가위바위보 시험

1. 빈 배경을 C로 등록하고, 고정된 카메라·배경·조명을 유지한다.
2. SELECT가 ROCK인지 확인한다. 청록색 사각형에 주먹을 놓고 DIP2 ON에서 실루엣을 확인한 뒤 B.
3. A로 PAPER 선택 → 같은 위치와 크기로 보를 제시 → B.
4. A로 SCISSORS 선택 → 같은 위치와 크기로 가위를 제시 → B.
5. TAUGHT R:1 P:1 S:1인지 확인한다. DIP2는 필요에 따라 OFF로 돌린다.
6. 손을 치웠다가 다시 각각 제시한다. SHAPE와 DISTANCE를 관찰한다.
7. 손 없음, 등록하지 않은 모양, 위치·크기를 바꾼 입력도 제시해 오분류/UNKNOWN을 기록한다.

세 모양을 모두 등록하기 전에는 NEED TRAIN이다. 한 종류만 등록한 상태에서 무조건 그 종류로 판정하지 않는다.
256개 이진 표본 중 서로 다른 비트 수가 DISTANCE이며 작을수록 등록 예시와 비슷하다.
최소 거리 48 이하, 둘째 후보와의 거리 차이 12 이상, 같은 후보 3프레임 지속일 때만 이름을 출력한다.
전경은 256개 중 6~220개여야 한다. 나머지는 UNKNOWN 또는 NO TARGET이다.
위치·크기 정규화, 회전 보정, 손가락 수 추정, 여러 학습 예시 축적은 구현하지 않았다.
등록하지 않은 물체도 비슷한 실루엣이면 오분류할 수 있다. 가위바위보 실사용 정확도는 아직 미확인이다.
