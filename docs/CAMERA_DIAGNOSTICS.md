# 카메라 색·움직임 진단

이 문서는 1차 진단 이미지의 기록이다. 여러 색 이름·움직임 방향·가위바위보 템플릿 시험은
[VISION_LAB.md](VISION_LAB.md)를 따른다. 현재 빌드 스크립트의 출력은 `board/vision_lab/usagi_vision_lab.bit`다.

2026-11-20 추가. B6 / F=50MHz를 유지한다.

## 사용할 이미지

새 진단 RTL로 생성한 `board/camera_diagnostics/usagi_camera_diagnostics.bit`를
Vivado Hardware Manager의 Program Device로 다운로드한다.
기존 `final.runs/impl_1/usagi_board_top.bit`에는 새 기능이 자동 반영되지 않는다.
격리 빌드 스크립트는 `scripts/build_camera_diagnostics.tcl`이며 final.xpr를 열거나 저장하지 않는다.
기존 GUI 프로젝트에서 Generate Bitstream을 다시 실행하는 방법도 가능하다.

## 최소 시험 순서

1. DIP4만 ON, DIP1·2·3·5 OFF. H를 눌렀다 놓고 영상을 확인한다.
2. 상단 첫째·둘째·넷째 상자가 초록인지 확인한다.
   각각 결과 수신, 정상 VGA 프레임, 센서 설정 완료다.
3. 노란 물체로 중앙 노란 사각형을 절반 이상 채워 1초 유지한다.
   아래 노란 막대가 흰 선(35%)을 넘으면 3프레임 뒤 LED3과 우사기가 반응해야 한다.
4. DIP2를 ON으로 바꾼다(DIP1은 계속 OFF).
   색 판정에 통과한 미리보기 픽셀이 자홍색으로 바뀐다. OFF면 원래 색으로 보인다.
   표시는 미리보기 전체, 집계와 반응은 중앙 노란 사각형에만 적용된다.
5. 파란 물체로 바꾸고 노란 막대·LED3·우사기 반응이 해제되는지 확인한다.
6. 카메라와 조명을 고정한다. 중앙 영역에서 손을 움직인다.
   노란 막대 바로 아래 자홍색 막대가 커지고 상단 다섯째 상자가 자홍색인지 본다.
   손을 정지하면 막대가 줄고 다섯째 상자는 어두워져야 한다.

| 결과 | 다음 확인 |
|---|---|
| 노란 물체가 자홍색으로 전혀 표시되지 않음 | 원본 영상의 색상, 밝기, RGB565 순서 및 색 임계값 |
| 자홍색 픽셀은 있지만 노란 막대가 작음 | 중앙 ROI 안의 물체 크기·위치 |
| 노란 막대가 35%를 넘지만 반응 없음 | 둘째 정상 프레임 상자, DIP1 OFF 및 DIP5 OFF |
| 정지 상태에도 움직임 막대가 큼 | 카메라 흔들림, 자동 노출, 조명 깜빡임·영상 잡음 |
| 다섯째 상자가 계속 주황 | 정상 연속 프레임을 확보하지 못함 |

## 검출 방식과 한계

- 색 판정은 기존 조건 유지: R>=160, G>=140, B<=100, R>B+60, G>B+50.
- 색 반응: 중앙 ROI의 35% 이상 3프레임이면 ON, 20% 미만 3프레임이면 OFF.
- 움직임은 매 프레임 4x4마다 한 픽셀을 추출하고 RGB565에서 근사 밝기를 계산한다.
  중앙 80x60=4800개 표본 중 이전 프레임 대비 밝기 차이가 24 이상인 표본을 센다.
  이 비율이 5% 이상이면 움직임 표시를 켠다. 흰 선은 5% 위치다.
- 첫 정상 프레임은 기준 영상이며 다음 정상 프레임부터 비교한다.
  잘못된 프레임·재설정 후에는 기준을 다시 확보한다. 영상 중단 시 유효 표시는 꺼진다.
- 손/방향/제스처 인식은 아니다. 밝기가 비슷한 물체의 움직임을 놓칠 수 있고,
  조명 변화도 영상 변화로 검출한다. 움직임은 진단 표시만 구동하며 학습 입력에는 연결하지 않는다.
- DIP1 ON에서는 DIP2가 원래 학습 허용 기능이다. 진단은 DIP1 OFF에서 실행한다.
- DIP5 컬러바는 센서 진단용이며 실제 물체 인식 성공으로 기록하지 않는다.

## 확인 수준

실물 색 검출 성공과 움직임 검출 성공은 아직 미확인이다.
카메라 테스트벤치는 정지 영상 0, 전체 밝기 변화 4800, 다시 정지 시 0,
잘못된 프레임 및 영상 중단 시 움직임 무효화를 검사한다.
2026-11-20 `run_checks.ps1 -Task camera` 통과. 기존 SCCB·색 검출·미리보기 검사도 함께 통과했다.
격리 빌드 배선 후 지정 타이밍 통과: WNS +6.190ns, WHS +0.026ns.
DRC 오류 0. 카메라 PCLK 비전용 클록 경로 허용 경고와 미리보기 BRAM의
비동기 리셋 유래 제어 경고 등이 남아 있으므로 경고 없는 설계라는 뜻은 아니다.
이는 실물 감지 성공의 증거를 대신하지 않는다.
